# AI Usage Log - KursusKu Pisang Pride (Halaman History)

| Masalah/tujuan | Referensi dari AI | Keputusan pengembang | Hasil uji |
| -------------- | ----------------- | -------------------- | --------- |
| Error `array_merge()` pada `history.php` | Memahami bahwa `array_merge()` di PHP 8 menolak argumen `null`, sehingga variabel yang belum didefinisikan menyebabkan TypeError. | Menghapus `array_merge` dengan variabel `$history` yang belum ada, dan mengambil data langsung dari session. | Halaman `history.php` tampil tanpa Warning dan Fatal error. |
| Sumber data history | Memahami cara menyimpan dan membaca data sementara menggunakan `$_SESSION`. | Menggunakan data otomatis dari pendaftaran (`$_SESSION['history']`), tanpa data dummy buatan sendiri. | Data peserta yang mendaftar otomatis muncul di tabel history. |
| History kosong | Memahami cara menangani array kosong dan nilai default dengan operator `??`. | Menambahkan pengecekan `is_array` dan pesan khusus saat belum ada data. | Tabel menampilkan "Belum ada data pendaftaran." tanpa error ketika session kosong. |
| Kolom Metode Belajar hanya menampilkan tanda strip (`-`) | Memahami bahwa key pada array harus sama antara file yang menyimpan dan file yang membaca data. | Menambahkan `learning_mode` pada array `$entry` di `process-registration.php`, lalu membacanya di `history.php`. | Penyebab ditemukan: `learning_mode` tidak ikut tersimpan ke session. Setelah perbaikan, pendaftaran baru menampilkan metode belajar. |
| Tampilan metode belajar | Memahami penggunaan array pemetaan (mapping) untuk mengubah kode menjadi label yang mudah dibaca. | Menggunakan label `offline` → Tatap muka, `online` → Online, `hybrid` → Hybrid pada tabel history. | Kode metode belajar ditampilkan sebagai label yang mudah dibaca. |
| Key data yang tidak lengkap | Memahami cara mencegah warning "Undefined array key" dengan nilai cadangan. | Menambahkan fallback `?? '-'` pada kolom nama, kursus, dan metode, serta `?? 0` pada total. | Tabel tetap tampil tanpa warning meskipun ada key yang kosong. |
| Data ganda saat refresh | Memahami cara mencegah data tersimpan dua kali saat halaman diproses ulang. | Membandingkan entri terakhir dengan entri baru sebelum menyimpan ke session. | Refresh halaman ringkasan tidak menambah baris ganda di history. |
| Dokumentasi bukti pengujian | Memahami cara mengambil screenshot tabel dengan DevTools (Capture node screenshot) dan Snipping Tool. | Mengambil screenshot tabel Test Matrix sebagai bukti pengujian. | Screenshot tabel tersimpan sebagai file PNG untuk folder bukti (evidence). |
